# Screenshots Giplay

Letakkan gambar tangkapan layar aplikasi di folder ini dengan nama berikut agar cocok dengan template galeri di `README.md`:

- `library.png` — Layar Library (daftar koleksi anime/video)
- `episodes.png` — Layar Daftar Episode dengan indikator progres
- `player.png` — Layar Video Player dengan Liquid Glass UI & Glowing Seekbar
- `controls.png` — Panel Bottom/Side Sheet (pilihan audio, subtitle, atau engine)

Setelah file ditambahkan, buka `README.md` lalu hapus tanda komentar `<!--` dan `-->` pada bagian **Tangkapan Layar**.
