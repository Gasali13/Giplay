# 📦 Changelog Rilis v1.0.1

Catatan rilis stabil untuk berkas biner `Giplay-v1.0.1.apk`.

---

## 🚀 Ringkasan Pembaruan
* **Optimasi Ukuran Biner (ABI Filtering)**:
  * Menggunakan target arsitektur `arm64-v8a` sehingga ukuran biner APK terpangkas menjadi ~45 MB (dibandingkan ~90+ MB jika menyertakan semua arsitektur lama).
* **Peningkatan Stabilitas Dual Engine**:
  * Memperbaiki masalah transisi permukaan (*Surface*) saat berganti antara [[ExoPlayer Engine]] dan [[MPV Engine]].
* **Perbaikan Sinkronisasi Audio & Subtitle**:
  * Peningkatan akurasi milidetik pada saat scrub video menggunakan [[Glowing Seekbar]] dan gestur [[Gesture & Controls]].
* **Penyempurnaan Pemindaian Media**:
  * Peningkatan kecepatan baca pada [[Media Repository]] untuk folder anime dengan ribuan episode.
